# EduVoice AI — Hackathon walkthrough

## Before presenting

- Confirm that `ASSEMBLYAI_API_KEY` is configured.
- Allow microphone access and test the output volume.
- Keep the text input available as an accessibility fallback.
- EduVoice is Live-AI-only; do not describe any response as a sample or Demo Mode answer.

## 0:00–0:25 — The problem

Many learners know what they want to ask but struggle to phrase it formally, especially when learning in a second language. Traditional learning tools also separate explanations, practice, and progress.

## 0:25–0:50 — Personal setup

Open EduVoice and select **Get started**. Enter a learner name, preferred language, learning level, daily goal, and any starting topic.

## 0:50–1:45 — General Voice Tutor

Open Voice Tutor. Leave **Any Topic** selected and ask:

> Mujhe recursion Urdu-English mein simple example ke sath samjhao.

Show the live transcript, detected topic, spoken explanation, and follow-up. Then ask:

> Give me a Python coding example.

Explain that the tutor remembers the current conversation rather than switching to unrelated content.

## 1:45–2:15 — Adaptive practice

Change Learning Mode to **Quiz Mode** and ask for a recursion question. Answer it verbally and show how the tutor continues one question at a time.

## 2:15–2:40 — Career tools

Open AI Interviewer and show its topic-based setup. Then open Resume Analyzer, upload a text-based PDF, choose a target role, and generate role-specific improvement guidance.

## 2:40–3:00 — Progress loop

Open the dashboard, Mistake Notebook, and My Progress. Show recent topics, recent questions, learning time, quiz performance, and recommended next steps.

## Closing line

EduVoice turns one spoken question into an explanation, contextual practice, and a clear next learning step—in the language the learner understands best.
